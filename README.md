# SWYNEX | Sales Data Exploratory Analysis

## 📊 Project Overview

This project was completed as part of the SWYNEX internship Task 2 – Exploratory Data Analysis.

The cleaned sales dataset was analysed using Excel to identify sales trends, product performance, category performance, city-wise sales and payment-method patterns.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Analysis & Visualization

## 📈 Analysis Performed

- Category-wise Sales Analysis
- Product-wise Sales Analysis
- Monthly Sales Analysis
- City-wise Sales Analysis
- Payment Method Analysis
- Key Business Insights

## 🔍 Key Insights

1. Electronics is the top-performing category, generating around ₹76.20 Cr and contributing over 50% of total sales.
2. Electronics and Accessories contribute nearly 80% of total sales.
3. Monitor is the highest-selling product, while Smartphone has the lowest sales among the products shown.
4. July records the highest monthly sales, while February and September are comparatively weaker months.
5. Payment methods are almost evenly distributed, with the major payment methods having around 2,000 orders each.
